# RDWorks 가 불편해서 직접 만들었습니다 – AI 로 만든 무료 레이저 커팅 프로그램 "Laser Tool"

레이저 커팅기를 쓰시는 분들이라면 한 번쯤 프로그램 때문에 스트레스를 받아 보셨을 겁니다.
저도 그랬습니다. 제 레이저는 **RUIDA(루이다) 제어기**를 쓰는 장비인데, 함께 쓰는 프로그램이 영 마음에 들지 않았습니다.
그래서 이번에 **인공지능(Claude)과 함께 레이저 커팅·각인 프로그램을 직접 만들어 봤습니다.**
만든 과정과 프로그램을 소개합니다.

![Laser Tool 편집 화면](https://raw.githubusercontent.com/robomecha/laser-tool/main/docs/images/screen-1.png)

---

## 왜 직접 만들게 되었나

제가 쓰는 레이저는 **RUIDA 제어기(컨트롤러)** 가 들어간 CO2 레이저입니다.
RUIDA 제어기는 국내외 CO2 레이저 커팅기에 많이 들어가는 제어기로, 기본 프로그램으로 **RDWorks V8** 이 함께 제공됩니다. 저도 그동안 RDWorks 로 작업해 왔습니다.
그런데 쓰면 쓸수록 불편한 점이 쌓였습니다.

- **USB 연결 오류**가 자주 납니다. 작업을 보내려는데 연결이 끊기거나 인식이 안 되는 일이 반복됐습니다.
- **UI 가 오래되고 불편합니다.** 메뉴가 복잡하고, 도형을 다루거나 레이어를 설정하는 흐름이 직관적이지 않습니다.

그래서 많이들 쓰는 **LightBurn** 으로 바꾸려고 했습니다. 확실히 편하고 잘 만든 프로그램이지만 **유료 프로그램**이라 라이선스 비용이 부담이 됐습니다.

"그럼 **RUIDA 제어기에 바로 연결되는** 프로그램을, 필요한 기능만 담아서 직접 만들어 보면 어떨까?"
요즘은 AI 가 코드를 꽤 잘 짜 주니까, **AI 에게 말로 설명하면서 하나씩 만들어 보기로 했습니다.**

---

## AI 와 함께 만든 과정

개발은 Anthropic 의 AI **Claude** 와 대화하면서 진행했습니다.
제가 한 일은 거의 **"이런 기능이 필요해"** 라고 말하는 것이었습니다.

> "LightBurn 같은 레이저 커팅 소프트웨어를 만들 거야. RDWorks 도 참고해 줘."
> "USB 로 연결이 안 되는데 어떻게 된 거야?"
> "복사, 배열 같은 편집 도구가 없어. 만들어 줘."
> "그림 그릴 때 치수가 mm 로 실시간 표시되게 해 줘."

이렇게 요청하면 AI 가 코드를 작성하고, 테스트하고, 문제를 찾아 고치는 과정을 반복했습니다.
처음에는 기본 편집기와 G-code 출력부터 시작해서, Ruida USB 연결, 텍스트·글꼴, 배열, 스냅, 정다각형, 실시간 치수, 한/영 화면 전환, 도움말, 그리고 실행 파일(exe)까지 차례로 붙여 나갔습니다.

직접 코드를 한 줄씩 짜지 않아도, **무엇이 필요한지 분명하게 말하면** 프로그램이 만들어진다는 게 신기한 경험이었습니다.

## 이렇게 생겼습니다

### 1. 편집 화면

![편집 화면 – 원형 코스터, 육각형 배열, 별 원형 배열, 이름표](https://raw.githubusercontent.com/robomecha/laser-tool/main/docs/images/screen-1.png)

LightBurn 처럼 **도형의 색 = 레이어**입니다. 오른쪽 레이어 패널에서 색깔마다 **절단(라인) / 채우기 각인 / 이미지 각인** 과 속도·출력을 정합니다.

- 선, 사각형, 타원, **정다각형·별**, 텍스트 그리기
- 텍스트는 **PC 에 설치된 글꼴**도 쓸 수 있고, 굵게·기울임, **원이나 곡선을 따라 쓰기**도 됩니다 (위 코스터의 "LASER · TOOL · CAFE")
- **격자 배열 / 원형 배열**, 오프셋, 합치기·빼기
- **스냅**(눈금 간격 1mm 단위 조정)과, 그리는 동안 **mm 치수가 실시간으로 표시**됩니다
- SVG, DXF, 이미지 파일 가져오기

### 2. 가공 미리보기

![가공 미리보기 – 경로 시뮬레이션과 예상 시간](https://raw.githubusercontent.com/robomecha/laser-tool/main/docs/images/screen-2.png)

실제로 레이저가 움직일 경로를 미리 볼 수 있습니다. 아래 슬라이더로 진행 상황을 돌려 보고, **예상 시간, 가공 거리, 공이동 거리**를 확인합니다.
각인을 먼저 하고 절단을 마지막에 하도록 순서를 자동으로 잡아 줍니다.

### 3. AI 로 그리기

![AI 대화 – 말로 요청하면 AI 가 그려 줍니다 (예시 화면)](https://raw.githubusercontent.com/robomecha/laser-tool/main/docs/images/screen-3.png)

만들다 보니 욕심이 생겨서, **프로그램 안에서 AI 에게 말로 그림을 부탁하는 기능**도 넣었습니다.
"지름 90mm 원형 코스터 만들어 줘. 가운데 '커피'는 채우기로 새기고…" 라고 하면 AI 가 도형을 그리고 레이어 설정까지 해 줍니다.
(위 화면은 기능을 보여 드리기 위한 예시 화면입니다. 앱 안 대화창은 Claude API 키가 필요하고, 키가 없어도 Claude Desktop 에서 연결해 쓸 수 있습니다.)

물론 **레이저 시작 버튼은 AI 가 누르지 않습니다.** 미리보기로 확인한 뒤 사람이 직접 시작합니다.

## 주요 기능 정리

| 구분 | 내용 |
| --- | --- |
| 그리기 | 선·폴리라인, 사각형, 타원, 정다각형·별, 텍스트 |
| 텍스트 | 내장 나눔고딕, PC 설치 글꼴, 굵게·기울임·외곽선 굵기, 곡선 따라 쓰기, 나중에 다시 수정 |
| 편집 | 이동·크기·회전, 정렬·반전, 복사·붙여넣기, 격자/원형 배열, 오프셋, 합치기·빼기·교집합, 실행 취소 |
| 보조 | 그리드 스냅·점 스냅, 실시간 mm 치수 |
| 가져오기 | SVG, DXF, PNG·JPG 등 이미지 |
| 가공 | 라인(절단) / 채우기 / 이미지(디더링) 레이어, 미리보기·예상 시간 |
| 장비 | **Ruida (RDWorks 컨트롤러) USB 직접 연결**, .rd 파일 내보내기, **GRBL** USB 연결, G-code 내보내기 |
| 기타 | 한국어 / English 화면, 도움말(F1), Windows 실행 파일(exe) |

### RUIDA 제어기 연결

제 장비가 RUIDA 제어기라서 가장 신경 쓴 부분입니다. LightBurn 처럼 **USB 로 RUIDA 제어기에 직접 연결**해서 작업 전송, 일시정지·정지, 프레임(작업 범위 확인), 조그 이동, 원점 복귀, 위치 표시를 할 수 있게 만들었습니다. 네트워크(이더넷)로 쓰는 경우를 위해 RDWorks 와 같은 `.rd` 파일 내보내기와 전송 도구도 넣었습니다.
RDC644x 계열(RDC6442G/S, 6445 등)을 기준으로 만들었고, 다른 모델은 장비 설정에서 통신 값을 바꿔 맞출 수 있습니다.

> ⚠ RUIDA 연결 기능은 아직 **실험 단계**입니다. Ruida 통신 방식은 공개돼 있지 않아서 공개된 분석 자료를 바탕으로 만들었습니다. 처음 쓰실 때는 꼭 **낮은 출력으로 조그 → 프레임 → 작은 도형** 순서로 시험해 보세요.

## 다운로드 · 실행 방법

소스 코드는 GitHub 에 **무료로 공개**해 두었습니다.

👉 **https://github.com/robomecha/laser-tool**

컴퓨터에 [Node.js](https://nodejs.org) 가 설치돼 있다면 아래처럼 실행할 수 있습니다.

```
git clone https://github.com/robomecha/laser-tool.git
cd laser-tool
npm install
npm run dev
```

그다음 **Chrome 또는 Edge** 에서 `http://localhost:5173` 을 열면 됩니다. (USB 레이저 연결은 Chrome·Edge 에서만 됩니다.)

`npm run build:exe` 로 **설치 없이 더블클릭으로 실행되는 exe 파일**도 만들 수 있습니다. 바로 내려받을 수 있는 실행 파일은 다음 업데이트 때 GitHub **Releases** 에 올릴 예정입니다.
